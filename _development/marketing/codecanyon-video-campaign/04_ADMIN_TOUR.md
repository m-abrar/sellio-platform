# Admin Tour Video

## Goal

Establish operational depth and reduce buyer uncertainty about managing a multi-vertical marketplace.

## Target Length

4-6 minutes. This is a confidence-building tour, not a complete training course.

## Storyboard

### 1. Administration overview — 00:00-00:40

- Open `/admin/welcome`.
- Show populated marketplace metrics and urgent actions.
- Switch briefly to the ecommerce dashboard if it adds distinct value.

**Narration point:** Sellio consolidates marketplace activity into one administration system.

### 2. Listings and moderation — 00:40-01:35

- Open `/admin/listings`.
- Filter or navigate between statuses.
- Open a listing edit/detail screen.
- Show proprietor identity, listing data, media, analytics link, and related activity.
- Demonstrate approval only on a disposable seeded listing.

### 3. Vertical operations — 01:35-02:15

Use a fast montage of:

- Products and orders
- Properties and bookings
- Autos and inquiries
- Events and ticket bookings
- Jobs and applications
- Services and appointments/quotes
- Classifieds and inquiries

Emphasize shared administration with vertical-specific operations.

### 4. Users, partners, and monetization — 02:15-03:20

- Buyers and partners.
- Roles and permissions.
- Plans and subscriptions.
- Payments and transactions.
- Commissions, wallets, or withdrawals where populated.

Avoid implying automated split payouts unless the exact recorded gateway configuration supports the claim.

### 5. Content and storefront control — 03:20-04:10

- Theme configuration.
- Page/content editing.
- Menu management.
- Blogs, testimonials, advertisements, or email templates.
- Show one safe content edit only if it can be restored immediately.

### 6. Platform configuration — 04:10-04:45

- General settings.
- Module enable/disable controls.
- Payment configuration with all secrets masked.
- System status, cache, and storage tools.

### 7. Close — 04:45-05:05

**Voice-over**

> From marketplace configuration to moderation, monetization, content, and reporting, Sellio keeps complex operations manageable from one place.

**Call to action**

`Explore the admin demo • Read the documentation • Available on CodeCanyon`

## Capture Requirements

- Use only seeded demo data and a disposable moderation record.
- Populate every dashboard card shown in the video.
- Mask gateway credentials, webhook secrets, email credentials, and private URLs.
- Do not record debug toolbars, stack traces, maintenance warnings, or failed image requests.
- Restore any changed status or content after recording.
