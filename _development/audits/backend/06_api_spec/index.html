Installation Overview

1 Environment Setup

Clone the repository and install the backend dependencies using Composer.

git clone https://github.com/sellio/platform.git
cd apps/backend
composer install

2 Database Initialization

Configure your .env file and execute the migration protocol.

php artisan migrate:fresh --seed
