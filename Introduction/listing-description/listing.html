Sellio — Multi-Purpose Multi-Vendor Marketplace Platform

Sellio is a self-hosted marketplace platform for products, properties, vehicles, events, jobs, services, and classifieds. A shared backend connects dedicated administration, seller, buyer, storefront, API, and mobile experiences.

Enable the marketplace modules your project needs, configure the available integrations, and adapt the included source code to your branding and business rules.

What Is Included

Laravel PlatformAdministration, REST API, public Laravel storefront, authentication, marketplace modules, and browser installer.
Next.js StorefrontAPI-powered storefront experiences for different marketplace industries.
Seller ApplicationReact workspace for listings, activity, orders, bookings, inquiries, memberships, wallet activity, and payouts.
Buyer ApplicationReact workspace for favorites, messages, notifications, purchases, bookings, applications, inquiries, and reviews.
Mobile SourceExpo and React Native customer application source for Android and iOS builds.
DocumentationInstallation, configuration, portal setup, module guidance, and operational notes.

Seven Marketplace Directions

  • Products: catalogs, inventory, carts, orders, checkout, favorites, and reviews.
  • Properties: amenities, visits, seasonal pricing, availability, add-ons, and bookings.
  • Vehicles: specifications, seller inventory, buyer inquiries, and follow-up.
  • Events: occurrences, ticket inventory, attendee details, bookings, and payments.
  • Jobs: job listings, employer information, applications, and buyer activity.
  • Services: packages, quotes, consultations, appointments, and customer activity.
  • Classifieds: categories, locations, saved listings, messaging, and inquiries.

Technology

  • Backend: Laravel 12
  • Runtime: PHP 8.2+
  • Storefront: Next.js 16
  • Web applications: React 19
  • Mobile: Expo 54 / React Native
  • Database: MySQL 8
  • Authentication: Laravel Sanctum 4
  • Realtime: Laravel Echo / Pusher-compatible configuration

Server Requirements

  • PHP: 8.2 or newer; PHP 8.3 recommended.
  • Database: MySQL 8.0+ or MariaDB 10.11+.
  • Web server: Nginx or Apache with URL rewriting enabled.
  • Memory: 512 MB minimum; 1 GB or more recommended when loading demo data.
  • PHP extensions: BCMath, Ctype, Exif, Fileinfo, GD, Intl, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML, and Zip.
  • Installer functions: exec and passthru must be enabled for the browser installer.
  • Writable directories: storage/ and bootstrap/cache/.

Third-Party Services

Payment gateways, maps, mail, realtime messaging, push notifications, and other external services require compatible regional availability and the buyer's own accounts, credentials, configuration, and applicable service fees. Supported integrations may be enabled or disabled according to the marketplace configuration.
