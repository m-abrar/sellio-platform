Technical Specifications

  • Backend: Laravel (PHP 8.2+)
  • Mobile App: Flutter 3.38.3
  • Frontend Website: Next.js (React)
  • Database: MySQL
  • Payment Gateways: PayPal, Stripe, Razorpay, Paystack, PhonePe, FlutterWave, Bank Transfer
  • Notifications: Firebase Cloud Messaging
  • Maps: Google Maps & Places API
  • Monetization: AdMob (Banner, Interstitial, Native)
  • SMS: Twilio Integration

Product Essentials & Requirements

  • Payment Gateways (per region) : Stripe, Razorpay, PayPal, Flutterwave, Paystack, PhonePe, PayTabs, DPO. Third-party transaction fees apply.
  • Google Maps API: Used for location autocomplete & map display. Charges apply once free allocation is exhausted.
  • OTP Service (pick one): Firebase, Twilio, or 2Factor. Free tiers available; charges apply after limits.
  • Google Gemini AI (Optional): For AI content generation without limits – configure paid Gemini key in Google Cloud.
  • AWS S3 (Optional): For cloud media storage instead of local server. AWS pricing applies.
  • VPS / Hosting Requirements: Apache or Nginx, any OS, 2 CPU cores, 2 GB RAM, 20+ GB disk space.
Following these requirements ensures optimal performance and avoids setup issues.
