Task: Build a Multi-Theme Next.js Engine with Isolated Architectures

Objective: Create a Next.js application that can switch between entirely different industry themes (e.g., Fashion, Tech, Grocery) using a "Dynamic Injection" strategy.

Core Requirements:

Theme Isolation: Create a src/themes/ directory. Each theme must be a self-contained folder containing:
Layout.tsx: The industry-specific shell (Header, Footer, Navigation).
Page.tsx: The industry-specific Home Page design.
styles.css: Vanilla CSS scoped only to that theme (including custom Google Fonts).
The Bridge: Configure src/app/layout.tsx and src/app/page.tsx as neutral bridges. They should import a configuration (e.g., from src/lib/theme.ts) and dynamically render the active theme's components.
Design Aesthetic: Each theme must be "Premium" and "High-End."
Fashion: High-contrast, serif fonts, minimalist luxury.
Electronics: Dark mode, neon accents, glassmorphism.
Grocery: Fresh, clean, organic green palette, high whitespace.
No Style Leakage: Ensure that CSS for one theme does not affect others. Use Vanilla CSS with theme-specific root classes (e.g., .fashion-theme).
Implementation: Start by initializing the Next.js app, setting up the directory structure, and implementing the first two themes with custom AI-generated imagery for the hero sections.
