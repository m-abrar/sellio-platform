5. Configuration

The primary configuration file is the .env file located in the root directory. Modify this file to customize application settings, mail drivers, and more.

Mail Service Setup

We recommend using a transactional email service (like Mailgun or SendGrid) for reliable delivery. Update the following $\texttt{.env}$ variables:

MAIL_MAILER=smtp
MAIL_HOST=smtp.mailgun.org
MAIL_PORT=587
MAIL_USERNAME=postmaster@yourdomain.com
MAIL_PASSWORD=your-smtp-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=no-reply@yourdomain.com

After changing configuration, always run: php artisan config:clear

7. Updating

Follow these steps carefully to update your application without data loss.

  • Step 1: Backup. Create a full backup of your **database** and **application files**.
  • Step 2: Replace Files. Replace all files with the new version, **except** for the .env file.
  • Step 3: Run Composer. Execute composer install --no-dev.
  • Step 4: Migrate Database. Run schema updates: php artisan migrate.
  • Step 5: Clear Cache. Ensure all old config is cleared: php artisan optimize:clear.

8. Troubleshooting

Encountering issues? Check these common problems first.

$\text{404}$ Errors on Internal Pages

This is usually an $\texttt{.htaccess}$ issue. Ensure your web server has the mod_rewrite module enabled and the $\texttt{.htaccess}$ file is present and correct in the public directory.

Blank Screen / $\text{500}$ Error

Set $\texttt{APP\_DEBUG=true}$ in your $\texttt{.env}$ file to see the specific Laravel error message. Also, confirm that the /storage and /bootstrap/cache directories have correct **write permissions ($\text{775}$ or $\text{777}$)**.
