System Requirements

Sellio leverages the power of Laravel 12. Ensure your server environment matches these high-fidelity specifications.

Environment

  • **PHP 8.2 or 8.3** (CLI & FPM)
  • **MySQL 8.0+** or **MariaDB 10.6+**
  • **Composer 2.x** for dependency management

Critical Extensions

  • **BCMath, Ctype, Fileinfo**
  • **GD/Imagick** (Image Processing)
  • **Intl, Zip, Exif** (High-res data)
Function Check

The exec() and passthru() functions must be enabled for the **Web Installer** to run migrations and seeders automatically.

Installation Guide

Deploying Sellio is a streamlined process. Follow these high-fidelity steps for a perfect launch.

1

Upload & Permissions

Upload the contents of the apps/backend folder to your public directory. Ensure storage and bootstrap/cache are writable.

2

System Audit

Navigate to /install. The wizard will perform a real-time health check on your server extensions and folder permissions.

3

Environment Provisioning

Configure your **Database Credentials** and **Mail Server (SMTP)**. The installer will automatically generate your .env file.

4

Structural Deployment

The installer will run migrations and seeders to populate the system. Do not close the tab during this process.

# Professional CLI Pipeline
composer install --no-dev --optimize-autoloader
cp .env.example .env
php artisan key:generate
# Configure DB in .env
php artisan migrate --seed --force
php artisan storage:link

API Integration

Sellio provides a robust RESTful API to power your Next.js storefront and mobile applications.

Authentication Flow

Requests must include a valid Bearer token in the Authorization header.

curl -X POST https://api.yourdomain.com/v1/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@sellio.com", "password":"password"}'

High-Fidelity Response Structure

All endpoints return a standardized envelope for reliable parsing:

{
    "success": true,
    "message": "Resource retrieved",
    "data": { ... },
    "meta": { "current_page": 1, "total": 150 },
    "errors": null
}

Troubleshooting

Issue: Database Connection Refused

Verify your DB_HOST and DB_PORT in the .env file. On shared hosting, ensure the database user is assigned to the database with **ALL PRIVILEGES**.

Issue: Image Upload Failures

Check your upload_max_filesize and post_max_size in php.ini. Also, ensure the storage/app/public directory is writable.
