Sellio Documentation

Welcome to the official technical manual for **Sellio**. This guide provides everything you need to deploy, configure, and scale your multi-tenant marketplace platform.

Overview

Sellio is a modern, high-performance marketplace engine built for professional distribution. It transitions from traditional fixed-theme platforms to a dynamic **Application-based architecture**, allowing you to host multiple marketplace verticals (Real Estate, Auto, Jobs) from a single core.

Modular Engine

Enable or disable marketplace verticals with a single toggle.

Executive UI

Premium glassmorphic design system for administration.

SaaS Ready

Built-in multi-tenancy, subscriptions, and security protocols.

Web Installation

Sellio comes with a high-fidelity **Web Installer** designed for effortless deployment on any hosting environment.

  1. **Upload**: Upload the project files to your server's root directory.
  2. **Navigate**: Visit yourdomain.com/install in your browser.
  3. **Step 1 (Audit)**: The installer will automatically check server permissions and extensions.
  4. **Step 2 (Database)**: Enter your DB credentials and configure SMTP settings.
  5. **Step 3 (Deployment)**: The installer will migrate the database and seed the "Golden Dataset."
  6. **Step 4 (Admin)**: Create your super-administrator account.
Security Protocol

After a successful installation, delete the /public/install directory immediately to prevent unauthorized access.

API Integration

Sellio provides a robust RESTful API built on Laravel Sanctum. This allows you to power external dashboards, mobile applications, or secondary storefronts.

Authentication

All protected requests require a Bearer token. Initialize the session via the login endpoint:

POST /api/v1/auth/login
Content-Type: application/json

{
    "email": "admin@sellio.com",
    "password": "password"
}

The response will contain a token to be used in the Authorization header for subsequent requests.

Unified Response Envelope

Every API response follows a consistent high-fidelity structure:

{
    "success": true,
    "message": "Resource retrieved successfully",
    "data": { ... },
    "meta": { ... },
    "errors": null
}
