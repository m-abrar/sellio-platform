System Requirements

Sellio leverages the power of Laravel 11/12. Ensure your server environment matches these high-fidelity specifications.

Environment

  • PHP 8.2 or 8.3
  • MySQL 8.0+
  • Redis (Optional but Recommended)

PHP Extensions

  • GD / Imagick (for Media Library)
  • BCMath & GMP (for Wallet)
  • Exif & Fileinfo

Installation Guide

Deploying Sellio is a streamlined process. Follow these high-fidelity steps for a perfect launch.

1

Dependency Resolution

composer install --no-dev --optimize-autoloader
2

Database Provisioning

Configure your .env file, then run the atomic migration pipeline:

php artisan migrate --seed --force

This command will execute the **Golden Dataset Seeder**, populating all 8 verticals with demo data.

The graphical web installer is currently in Alpha and recommended only for development environments.

Financial Ecosystem

The platform features a double-entry accounting system for secure financial transactions.

Atomic Wallet

Powered by bavix/laravel-wallet, ensuring every credit/debit is mathematically validated.

Withdrawal Pipeline

Partners can request payouts. Admins review and approve via Admin -> Financials -> Withdrawals.

Payment Gateways

Current stable integrations: Stripe, PayPal. Regional gateways (Razorpay, Flutterwave) are planned for v2.2.0.

Maintenance Hub

Exclusive diagnostic tools developed for platform stability.

System Health Audit

Real-time verification of folder permissions and PHP extension status. Accessible via Admin -> System -> Status.

Atomic Purge

Unified cache clearing for routes, views, and config without SSH access. Accessible via Admin -> System -> Maintenance.

Technical Architecture

Sellio is built for developers who value clean, maintainable code.

Service Layer Pattern

Controllers do not contain business logic. Instead, they proxy requests to specialized Services:

// Example: Listing Creation
public function store(ListingRequest $request) {
    return $this->listingService->create($request->validated());
}

Core Traits

  • HasImageAccess: Unified Spatie Media Library management.
  • HasAnalytics: High-performance view tracking.
  • ManagesApproval: Standardized moderation workflows.
