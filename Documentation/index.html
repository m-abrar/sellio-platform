Environment Specification

Sellio requires a modern server environment to handle multi-vertical processing.

  • PHP Version: 8.2 or 8.3
  • Database: MySQL 8.0+ or MariaDB 10.11+
  • Server: Nginx or Apache with mod_rewrite
  • Memory: 512MB RAM (minimum)
  • Extensions: BCMath, Ctype, Fileinfo, GD/Imagick, Intl, Mbstring, OpenSSL, PDO, Tokenizer, XML, Zip

Installation Pipeline

1

Asset extraction & dependency sync

Upload the apps/backend folder to your server. Run the composer orchestration:

composer install --no-dev --optimize-autoloader
2

Environment setup

Initialize your environment variables and generate the secure application key:

cp .env.example .env && php artisan key:generate
3

Atomic schema deployment

Ensure your .env database credentials are set, then execute:

php artisan migrate --seed --force && php artisan storage:link

This runs the Golden Dataset Seeder, populating all enabled verticals with high-fidelity sample data.

1

Payload upload

Upload the contents of the backend folder to your web root (usually public_html). Distribution packages include pre-built vendor/ and public/build/ assets.

2

Database provisioning

Create a new MySQL database via cPanel and a user with full privileges. Note the name, user, and password.

3

Web installer

Access your domain in the browser (e.g. yoursite.com/install). The guided wizard handles .env generation, migrations, module selection, and demo seeding.

Core Configuration

The primary configuration hub is the .env file. After any modification, run php artisan config:clear.

Mail service setup

We recommend a transactional service like Mailgun or SendGrid for platform notifications.

MAIL_MAILER=smtp
MAIL_HOST=smtp.mailgun.org
MAIL_PORT=587
MAIL_USERNAME=postmaster@yourdomain.com
MAIL_PASSWORD=your-secure-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=no-reply@yourdomain.com

Background Orchestration

Critical platform features like expiration tracking and notifications require background workers.

Scheduler (cron job)

* * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1

This runs cleanup tasks, recurring payments, and email queues every minute.

Maintenance & Updates

Follow this workflow to update your platform without data loss.

1. Payload swap

Replace all files in your installation directory except .env and storage/app/public.

2. Schema sync

Run php artisan migrate to sync new database columns and tables with your existing data.

3. Cache purge

Run php artisan optimize:clear to ensure new configuration and routing changes are registered.

Financial Ecosystem

Sellio manages the flow of capital between buyers, sellers, and the platform admin.

Atomic wallet protocol

Powered by bavix/laravel-wallet, every transaction uses double-entry bookkeeping to prevent balance discrepancies during high-concurrency operations.

Withdrawal lifecycle

  • 1. Partner requests payout
  • 2. Admin reviews bank/method data
  • 3. Admin approves → wallet debited
  • 4. Settlement record finalized

Payment gateways

Configure Stripe and PayPal secrets via Admin → Settings → APIs. Native webhook support is included for automated order fulfillment.

Advanced Backend Engineering

Sellio's codebase is designed to be modified and extended by developers.

Service layer pattern

Business logic is decoupled from the HTTP layer. Major modules (e.g. PropertyService, FinancialService) can be called from web, API, or CLI without rewriting logic.

Modular traits

  • HasImageAccess: unified Spatie Media Library management.
  • HasAnalytics: non-blocking engagement tracking for listings.
  • ManagesApproval: standardized moderation and approval workflows.

API Integration

Sellio ships with a documented REST API for mobile apps, headless storefronts, and third-party integrations.

Scramble documentation

Auto-generated OpenAPI docs are available at /docs/api when enabled. Endpoints reflect live request validation rules.

Sanctum authentication

Issue bearer tokens for SPA and mobile clients. Protect routes with standard Laravel middleware and permission gates.

Configure CORS, portal URLs, and API base paths in .env and the admin settings panel so buyer and seller SPAs resolve the correct backend host.

Troubleshooting

Common issues and their resolutions.

404 errors on internal pages

Usually caused by missing .htaccess (Apache) or incorrect try_files (Nginx). Ensure mod_rewrite is enabled.

Blank screen / 500 error

Check storage/logs/laravel.log. This is often incorrect folder permissions — ensure storage and bootstrap/cache are writable (chmod 775).

Missing styles on login

Run npm run build to generate public/build/, or deploy the distribution ZIP which includes pre-built assets. A guest CSS fallback covers basic login styling when the manifest is absent.
